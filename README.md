# Lab 8 — Trees and Binary Search Trees

## Course
CS 20 — Advanced Programming with C++

## Objective
This lab focuses on linked-tree structures and especially the binary search tree (BST). Students will build a pointer-based tree where each node stores a value and two child pointers.

## Required tasks

Students must implement a linked BST with the following behaviors:

- insertion of integer values;
- search for a value;
- deletion of a node;
- minimum and maximum value lookup;
- traversal in-order, pre-order, and post-order;
- size and emptiness checks;
- tree height calculation;
- correct dynamic memory management.

## Search and algorithm analysis

Students should also analyze and discuss the following:

- time complexity of insertion, search, and removal;
- worst-case versus average-case complexity;
- effect of tree height on search efficiency;
- best-case vs. worst-case tree shape;
- comparison between recursive and iterative implementations;
- when a BST is efficient and when it becomes inefficient.

## Required deliverables

Students must submit:

- all C++ source and header files;
- the linked-node BST implementation;
- search and traversal methods;
- unit tests for normal, boundary, and failure cases;
- a short complexity analysis document.

## Quality expectations

- meaningful names;
- appropriate comments describing recursive logic and edge cases;
- correct pointer handling and memory cleanup;
- const-correctness where appropriate;
- no unnecessary global variables;
- clean formatting and modular design.

## Important note
The starter project intentionally contains function stubs and tests that fail until the student completes the implementation. The goal is to force students to reason about tree structure, pointer linkage, BST ordering, search, and algorithmic complexity.
